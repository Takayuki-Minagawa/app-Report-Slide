# HTMLの保存・再編集とコンピューターユース

SVG編集、切り抜き・注釈・出典、複合領域、複数系列グラフ、閲覧時の拡大と補足は [図表編集ガイド](./figure-authoring.ja.md) を参照してください。図表サンプルは左の「サンプルを開く」から指定したときだけ開きます。

## 起動・復元・サンプル

起動時は空のReportを表示します。復元画面は自動で開きません。左下の **未保存の作業を確認** から候補を選び、**復元する** または **削除する** を実行できます。**閉じる（候補を保持）** はコピーを削除しません。復元後も元のコピーは残り、不要になった候補だけを明示的に削除できます。過去の候補を残したまま新しい作業を始めても、新しい作業は別にブラウザー内へ一時保存されます。現在の未保存変更を復元で置き換える場合は確認します。

**サンプルを開く** を展開するとReport／Slideの例を開けます。章別Report／Slideの操作も、必要なときに **章別プロジェクト** を展開します。

## HTMLを開いて保存する

1. **HTML・原稿を開く** から `.html`／`.htm` を選択します。ローカル画像は一緒に選べます。
2. 取り込み確認でページ数、要素数、変換結果・制限、ページごとのプレビューを確認します。
3. **確認して取り込む** を押します。キャンセル時は現在の原稿を変更しません。
4. 本文・表・画像・配置を編集し、ヘッダーの **HTML** で保存します。ボタンの説明は「編集できるHTMLを保存」です。
5. ブラウザーでダウンロード結果を確認します。後日、同じHTMLを開いて編集を再開できます。

自アプリHTMLにはバージョン付きのDocumentDataと画像を保持します。Reportのページ設定、Slideのテーマ・配置・文字サイズ、表、数式、発表者ノートなどを復元します。壊れた編集データや未知バージョンを、通常の外部HTMLとして黙って取り込み直すことはありません。

HTML出力は未適用Markdownも含みますが、編集画面の下書きやUndoは変更しません。「ダウンロード開始」はディスク保存の保証ではないため、未保存表示・復旧用コピーは維持します。保存状態欄は未保存、ブラウザー内への一時保存、HTMLダウンロード開始を区別します。

章別Report／SlideのHTMLは出力範囲に応じて現在の章、または有効な章を結合した単一文書になります。章構成・除外した章を含む原本は **プロジェクトZIP** に保存します。

## 外部HTMLの対応範囲

- 見出し、段落、リスト、表、画像、取得可能な数式文字列を編集可能な文書に変換します。
- SVGは安全化した1枚の画像として保持します。図内の線や文字を個別編集する機能ではありません。
- reveal.js等の一般的なスライド構造を認識します。認識できないHTMLは単一Reportとして取り込みます。必要に応じてMarkdownで `type: slide` と区切りを指定してください。
- 元のCSS配置、JavaScript、canvasによる動的グラフ等の完全再現は行いません。再現しない要素や文章化した要素を確認画面と取込後の結果欄に表示します。変換レポートと変換前のHTML原文をメタデータに保持します。「保持した取込原データ」は必要なときだけ開いて確認・保存できます。
- 外部のスクリプトやイベント属性は実行しません。HTMLそのものをプレビュー領域へ挿入せず、変換済み文書を表示します。
- 外部URLの画像は通信が必要です。単一HTMLでオフライン表示したい画像はローカルファイルとして一緒に取り込んでください。
- 外部HTMLは5 MiB、自アプリHTMLは150 MiB、画像は1件20 MiB・合計50 MiBが上限です。構造の深さ・要素数にも上限があります。

## Slideのデザインと文字サイズ

右の **スライドデザイン** で3テーマ（Beamer Simple、Technical、Paper Light）と複合領域を含む9配置（標準、表紙、2列比較、本文の右に図、図の下に説明、表中心、数式中心、数値強調、複合領域）を選べます。本文量プリセットとタイトル・見出し・本文・表・補足のサイズを別々に調整できます。サイズは幅920 pxを基準とし、表示幅に応じて拡縮します。

適用範囲は現在・選択・全ページです。個別設定済みページを維持する選択肢もあります。**変更をプレビュー** で変更前後と影響ページ数を確認し、適用します。直前のデザイン変更は専用ボタンでまとめて取り消せます。本文・数値・手動指定した図の位置は変更しません。配置は内容の順序や見出しを基にするため、長いページは検査後に分割してください。

新しい配置・役割別文字設定は完成プレビュー、HTML、PDFで使用します。PPTXは独自の組版で出力するため、同じ見た目を再現するものではありません。

## ページ・要素の選択と検査

左のページ番号・タイトル検索で移動し、ページ内の本文・図・表等を選べます。図のPropertiesにはX／Y／幅／高さ（スライド全体に対する%）、縦横比固定、左右中央揃えを用意しています。

**全ページをチェック** → **検査を実行** で、ページを1枚ずつ描画して、はみ出し、ブロックやフッターとの重なり、小さい文字を調べます。結果から対象へ移動できます。意図した重なりはその文書版の検査中だけ除外でき、編集後は再検査が必要です。内容の自動削除や自動縮小はしません。画像の読込失敗や計測できない状態も知らせます。

SVG画像内部の文字サイズ、すべての視覚的重なり、配色の品質、文章・統計解釈の正しさまでは保証しません。ページ区切りはMarkdownまたはスライドのページ操作で修正できます。章管理・並べ替え・対数軸・誤差棒にも対応します。閲覧HTML専用の本文検索はありません。

「出力比較・印刷」でHTMLと印刷用紙を比較し、ブラウザーの印刷画面から検索できるPDFを保存できます。詳しい書式・部品再利用・表分割・印刷時の制限は [図表編集ガイド](./figure-authoring.ja.md) を参照してください。
