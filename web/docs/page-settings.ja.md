# Reportのページ設定

右の「プロパティ」→「ページ設定」で値を入力し、「ページ設定を適用」を押します。「標準設定に戻す」は初期値を即時適用します。編集中の設定は適用するまで文書には反映されません。

| 項目               | 設定範囲                         | 標準値  |
| ------------------ | -------------------------------- | ------- |
| 用紙               | A3 / A4 / A5 / B5（JIS）/ Letter | A4      |
| 向き               | 縦 / 横                          | 縦      |
| 上・下・左・右余白 | 各0〜70 mm                       | 各20 mm |
| 本文サイズ         | 8〜24 pt                         | 10.5 pt |
| 段落先頭の字下げ   | 0〜8字（em）                     | 0字     |
| 行間               | 1〜3倍                           | 1.85倍  |
| 段落間隔           | 0〜36 pt                         | 12 pt   |

余白を引いた本文領域は幅・高さとも40 mm以上必要です。字下げと段落間隔は最上位の本文段落に適用します。見出し、表内の文章、箇条書き、引用、数式には段落先頭の字下げを適用しません。

## 保存と再開

- 単一Report：適用後、ヘッダーのMarkdownまたはJSONで保存します。ファイルを読み直すとページ設定が復元されます。
- 章別プロジェクト：設定は全章共通です。「プロジェクトZIPを保存」で構成と設定を一緒に保存します。「全体Markdown」「全体JSON」にも含まれます。ヘッダーの章単体保存にはプロジェクト共通設定は含まれません。
- 端末内の復旧用コピーにも適用済み設定を含めます。復旧用コピーは正式なファイル保存の代わりにはなりません。
- Markdown編集モードや未適用のMarkdown下書きがある間はページ設定をロックします。原稿を適用または破棄してから変更してください。

MarkdownではFront Matterの `page_settings` に以下の形で保存します。手で記述する場合はすべての項目を指定してください。不正な型、範囲外、未知の項目、本文領域が狭すぎる値は読み込み時に拒否します。

```yaml
---
type: report
title: 技術レポート
page_settings:
  paper: A4
  orientation: portrait
  margin_top: 20
  margin_bottom: 20
  margin_left: 20
  margin_right: 20
  font_size: 10.5
  first_line_indent: 1
  line_height: 1.5
  paragraph_spacing: 6
---
```

既存文書の直下の `paper` / `orientation` も読み取ります。両方ある場合は `page_settings` を優先します。新しい設定を持たない文書は標準値で表示し、元のメタデータは保持します。

## 表示の範囲

用紙の幅・高さと余白、本文のサイズ・間隔を編集画面と完成プレビューへ反映します。用紙は表示領域の幅に合わせて縮小します。Slideは既存の16:9のままです。

ページ分割は従来どおり明示的な改ページを使用します。内容が多ければページは縦に伸びるため、用紙に収まるかの厳密な判定、自動改ページ、印刷・PDF出力は提供しません。
