# Reportのページ設定

右の「プロパティ」→「ページ設定」で値を入力し、「ページ設定を適用」を押します。「標準設定に戻す」は初期値を即時適用します。編集中の設定は適用するまで文書には反映されません。

| 項目               | 設定範囲                         | 標準値           |
| ------------------ | -------------------------------- | ---------------- |
| 用紙               | A3 / A4 / A5 / B5（JIS）/ Letter | A4               |
| 向き               | 縦 / 横                          | 縦               |
| 上・下・左・右余白 | 各0〜70 mm                       | 各20 mm          |
| 本文サイズ         | 8〜24 pt                         | 10.5 pt          |
| 段落先頭の字下げ   | 0〜8字（em）                     | 0字              |
| 見出し直後の本文   | 通常の本文と同じ／下げない       | 通常の本文と同じ |
| 行間               | 1〜3倍                           | 1.85倍           |
| 段落間隔           | 0〜36 pt                         | 12 pt            |

余白を引いた本文領域は幅・高さとも40 mm以上必要です。字下げと段落間隔は最上位の本文段落に適用します。見出し、表内の文章、箇条書き、引用、数式には段落先頭の字下げを適用しません。

## 本文書式をまとめて選ぶ

「本文書式プリセット」を選び、見本で先頭行と段落間隔を確認してから「ページ設定を適用」を押します。

| プリセット                 | 通常の本文 | 見出し直後の本文 | 段落間隔 |
| -------------------------- | ---------- | ---------------- | -------- |
| 和文報告書                 | 1字下げる  | 1字下げる        | 0 pt     |
| 見出し後は下げない         | 1字下げる  | 下げない         | 0 pt     |
| 字下げなし・段落間を空ける | 下げない   | 下げない         | 12 pt    |

プリセットは字下げと段落間隔だけを変更します。用紙・余白・本文サイズ・行間と、段落ごとの例外は保持します。値を個別に調整してカスタム書式にすることもできます。既存の文書を開くだけでプリセットへ変更されることはありません。

「見出し直後」は、その見出しに続く最初の本文段落です。空段落や明示改ページを挟んでも同じ規則を使います。図・表・数式・リストなどが間にあれば、次の本文は通常の段落として扱います。ページの先頭にあるという理由だけでは、字下げを解除しません。

## この段落だけ下げる・下げない

Reportの本文にカーソルを置き、段落の先頭行の設定を選びます。

- **文書に従う**：通常本文・見出し直後の規則に従います。文書全体の設定を変えると、この段落も追随します。
- **1字下げる**：この段落を1字下げます。全体の設定を変えても1字を保ちます。
- **下げない**：この段落を0字にします。全体の設定を変えても下げません。

対象は最上位の本文段落です。見出し・表セル・リスト・引用内では本文用の設定を適用しません。複数の対象段落を選んでまとめて変更できます。数式の後に「ここで、…」と説明を続けたい場合は、その段落を **下げない** にします。単語や数式の有無から自動では判定しません。

1字は本文サイズの1emに対応します。文字サイズに追随し、用紙幅や余白を変えても1字分を保ちます。手入力の全角空白やタブは削除されないため、先頭空白と設定による字下げが重ならないよう確認してください。

既存の **文字位置ルーラー** による1行目の設定は、そのまま保持します。段落の **文書に従う**・**1字下げる**・**下げない** を選ぶと、ルーラーの左右位置を残して先頭行の指定だけを置き換えます。ルーラーの1行目を直接動かすと、先頭行は再びルーラー指定になります。ルーラーの割合指定と「1字」の指定は異なるので、用紙幅を変えたときの追随方法も異なります。

## 保存と再開

- 単一Report：適用後、ヘッダーのMarkdownまたはJSONで保存します。ファイルを読み直すとページ設定が復元されます。
- 章別プロジェクト：設定は全章共通です。「プロジェクトZIPを保存」で構成と設定を一緒に保存します。「全体Markdown」「全体JSON」にも含まれます。ヘッダーの章単体保存にはプロジェクト共通設定は含まれません。
- 端末内の復旧用コピーにも適用済み設定を含めます。復旧用コピーは正式なファイル保存の代わりにはなりません。
- Markdown編集モードや未適用のMarkdown下書きがある間はページ設定をロックします。原稿を適用または破棄してから変更してください。

MarkdownではFront Matterの `page_settings` に以下の形で保存します。手で記述する場合、従来の項目はすべて必要です。追加の `after_heading_indent` だけは省略でき、省略時は `same`（通常の本文と同じ）として扱います。不正な型、範囲外、未知の項目、本文領域が狭すぎる値は読み込み時に拒否します。

```yaml
---
type: report
title: 技術レポート
page_settings:
  paper: A4
  orientation: portrait
  margin_top: 20
  margin_bottom: 20
  margin_left: 20
  margin_right: 20
  font_size: 10.5
  first_line_indent: 1
  after_heading_indent: none
  line_height: 1.5
  paragraph_spacing: 6
---
```

既存文書の直下の `paper` / `orientation` も読み取ります。両方ある場合は `page_settings` を優先します。新しい設定を持たない文書は標準値で表示し、元のメタデータは保持します。

段落個別の指定は、本文直後の独立した属性行に保存します。`inherit` は文書規則に従い、数値は0〜8字です。新しい指定がない段落は、既存ルーラーがあればその位置を優先し、なければ文書規則に従います。

```markdown
この段落は文書の設定に従います。
{first_line_indent=inherit}

この段落だけ1字下げます。
{first_line_indent=1}

ここで、各記号は次の量を表します。
{first_line_indent=0}
```

属性行はKUMIの拡張記法です。一般のMarkdownビューアが同じ書式を表示するとは限りません。[本文書式サンプル](../examples/example-report-formatting.md)を開くと、見出し・通常段落・数式後の例外・表・改ページを確認できます。

## 表示の範囲

用紙の幅・高さと余白、本文のサイズ・間隔を編集画面と完成プレビューへ反映します。通常の用紙表示は表示領域の幅に合わせて縮小します。実ページ番号を有効にした完成プレビューは、改行位置を保つため用紙の幅を固定し、狭い画面では横にスクロールできます。Slideは既存の16:9のままです。

編集用の原稿は明示的な改ページを保持します。**報告書の構成 → 目次に実際のページ番号を表示** を有効にすると、完成プレビュー・HTML・印刷・直接PDFでは用紙に合わせて自動改ページします。無効な場合、完成プレビューの長い論理ページは縦に伸びます。本文書式はWordにも反映し、文字サイズから字下げ幅を計算しますが、Wordのフォントや改行位置は表示環境によって異なります。

ヘッダーの **PDF** は紙面を画像として保存するため、文字を検索できません。実ページ番号が有効なら組版済みの紙面を保存し、無効な長いReportは用紙高さで分割するため、段落・表の途中で切れる場合があります。検索可能なPDFは **出力比較・印刷 → 印刷／PDF保存** を使います。実ページ番号が有効な場合は、組版完了後に同じ用紙・向き、倍率100%、ブラウザーのヘッダーとフッターを無効にして印刷してください。ページ下端への脚注配置や柱は未対応です。詳しくは [報告書の構成](./report-structure.ja.md#ページと出力) を参照してください。
