# LaTeX風の文書機能

## 使い方

1. Navigatorで見出し・図・表・ブロック数式を選択します（表内の本文選択でも表を選択できます）。
2. Propertiesで「参照ラベル」「キャプション」「番号付け」を設定し、「属性を適用」を押します。図は幅・配置・代替テキストも編集できます。
3. 参照を置く本文位置を選び、Propertiesの「参照先ラベル」に入力して「参照を挿入」を押します。
4. 文書の「目次」「節番号」を必要に応じて有効にします。完成プレビューでは番号・リンクを自動生成します。
5. 「改ページ」または「スライドを区切る」で、選択中の最上位ブロックの後ろに区切りを追加します。プレビューは全ページを縦に表示します。

未適用Markdown下書きがある間、Propertiesなどの文書変更操作は無効です。先に適用するか破棄してください。参照先未定義・ラベル重複は警告だけで、原稿を消したり保存を止めたりしません。本文・要素属性の変更はUndo/Redo対象ですが、テーマ・目次・節番号・スライド番号の文書設定は対象外です。

## Markdown構文

属性は対象ブロックの直後に、独立した1行で指定します。キーの重複・未知キー・不正値は読込エラーとなり、適用前の原稿を保持します。文字として書く場合は先頭の記号をバックスラッシュでエスケープしてください。

```markdown
# 解析概要

{#sec:overview}

図 [@fig:response] と式 [@eq:motion] を参照する。

![応答](assets/response.svg)
{#fig:response width=65% align=right caption="最大応答" numbered=true}

$$
M\ddot{x}+C\dot{x}+Kx=F(t)
$$

{#eq:motion caption="運動方程式"}

| 項目     | 値      |
| -------- | ------- |
| 最大変位 | 24.5 mm |

{#table:result caption="結果一覧"}

::: pagebreak
:::
```

- `label`は英字で始まる128文字以内の英数字・`:`・`.`・`_`・`-`。任意の名前を使えます。`#fig:name`と`label="fig:name"`は同じ意味です。
- 参照の正式な記法は`[@label]`です（裸の`@label`は通常の本文）。既存Markdownリンク・コード・数式の中は参照として解釈しません。
- `caption`はプレーンテキスト。引用符・改行・バックスラッシュにはJSON文字列のエスケープ（`\"`、`\n`、`\\`）を使います。
- 図・表・式は別々のカウンター。`numbered=true`は番号を有効、`false`は無効にします。省略時はキャプションまたはラベルがある要素だけを採番し、旧文書の見た目を維持します。
- 見出しはFront Matterの`number_sections: true`で採番します。個別属性`numbered=true`／`false`は文書設定を上書きします。飛ばした上位階層は1で補完します。除外した要素はカウンターを消費しません。
- `toc: true`で最初のページに目次、`slide_number: false`でスライド番号を非表示にします。
- スライド区切りは`::: slidebreak`と次行の`:::`。`pagebreak`／`slidebreak`はどちらの文書種別でも明示的区切りとして保持します。
- 区切りは文書直下のみ。先頭・末尾・連続する区切りは空ページを作ります。従来の`---`は水平線のままです。

内部`nodeId`は編集用、`label`は安定した参照用です。Markdown再読込でnodeIdが変わってもlabelは保持され、番号は都度再計算します。番号自体は保存しません。

## JSON互換

既存の「Markdownを開く」からDocument JSONも選択できます。画像を併せて選ぶ手順はMarkdownと同じです。schemaVersion 1と2を検証し、読み込み後とJSON保存時は2に移行します。未知のバージョンは拒否します。v1の本文・metadata・nodeIdを削除しません。

## 制限

この段階は手動のページ／スライド区切りです。長い本文の自動ページ割り、厳密なA4高さ、印刷用改ページ、スライドの縮小フィットは提供していません。長い内容は区切りを追加してください。

KaTeXは数式表示を担当し、LaTeX文書クラス・任意パッケージ・TeXコンパイル・完全な`.tex`互換は対象外です。
