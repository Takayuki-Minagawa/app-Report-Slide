# 図表を作り、保存後も編集する

## 最初に試す

左の **サンプルを開く → 図表サンプル（5ページ）** で、模式図、原図＋比較表＋条件、全幅表、2系列グラフ、読者向け補足を試せます。数値と原資料は機能説明用の架空データです。起動時には自動で開きません。

1. ページ番号・タイトルで対象を検索し、**編集対象一覧** から図や表を選びます。
2. 図表の挿入先を **選択ブロックの後／現在のページ末尾／カーソル位置** から選びます。標準では選択した表の外へ挿入されます。挿入結果にはページ番号を表示します。
3. 右側の設定を変更して適用します。本文の移動・複製、図・表・グラフの変更はUndoで戻せます。スライドデザインには専用の直前変更取消があります。文献・補足などの文書設定は本文のUndoとは別です。
4. **HTML** または **ZIP** を保存します。別のブラウザーのKUMIへ取り込み直し、図解の部品・表の値・PDFのページ・切り抜き・出典を再編集できます。

## 構造化図解を作る

ツールバーの **図形で図解を作る** で図解を挿入し、図を選んで右側の **図形をドラッグして編集** を開きます。矩形・楕円・テキスト・線・矢印を追加し、それぞれを部品として編集できます。

- 図形をドラッグして移動し、選択枠の右下でサイズを変更します。位置・幅・高さの数値入力や、矢印キーによる移動にも対応します。数値はEnterまたは入力欄から移動すると反映します。
- 文字、塗り、線の色・太さを指定できます。線・矢印の始点と終点には自由な座標または図形を指定し、図形へ接続した線は移動・リサイズに追従します。
- **図解の部品一覧** で複数選択し、**図形をグループ化** するとまとめて移動・リサイズできます。グループ解除、複製、削除、最前面・最背面への移動も可能です。
- **図形をロック** すると直接の移動・サイズ変更・属性変更を止められます。変更するときは同じ場所からロックを解除します。
- 編集画面の **図形の変更を元に戻す／やり直す** を使用できます。1回のドラッグは1回のUndoで戻ります。**図へ適用** するまで文書は変わらず、適用後は本文側のUndoでも戻せます。

1つの図解には最大200図形・300接続線を保存できます。HTML／ZIP／JSON／Markdownは部品と接続関係を保持します。任意の外部SVGをこの部品構造へ自動分解する機能はありません。

## SVG図解と原図

**SVG図解を挿入** は3状態の模式図を追加します。図を選択し、**SVGソース・ラベルを編集** を開くと、ラベルの文字と矢印の向きを変更できます。任意のSVGファイルを読み込み、ソースを修正することもできます。

通常の画像は画像としての配置、SVG原本を指定した図はソース編集が可能、と画面に表示します。SVG原本は文字列として保持し、表示用には実行要素・外部参照・埋込画像・styleを除去したコピーを使います。SVGソースは1 MBまでです。外部HTMLから変換したSVG画像の内部編集には、必要に応じてSVG原本を指定してください。

**原画像の切り抜き・注釈** は元画像に対する割合で範囲を指定します。切り抜きを解除すれば原画像全体へ戻せます。矢印・囲み・番号・説明を別レイヤーとして追加でき、位置・色・文字サイズを数値で変更できます。注釈の座標は元画像に固定されるため、切り抜き範囲を変えても同じ箇所を指します。原画像の縦横比は保持します。

**図の由来・共有文献** には文献ID、題名、著者・年、URLを登録します。同じ文献IDを使う図は、文献の訂正を共有します。PDFページ、論文内ページ、図表番号、由来（原図／一部切り抜き／再作図／概念図）、注記は図ごとに指定します。共有文献を保存したあと **図の編集を適用** で図との関連を確定します。由来と文献情報はキャプションに続けて表示します。

外部SVGはソース・ラベル・矢印の編集、**図形で図解を作る** から作った図は部品の編集、という別の編集方式です。外部SVGの任意の要素を自動でドラッグ可能な部品へ変換することはありません。

## PDFページから図を取り込む

Report／Slideのツールバーで **PDFから図を追加** を選びます。PDFはブラウザー内で処理し、サーバーへ送信しません。

1. PDFファイルを選び、**PDFページ** の一覧から取り込むページを選択します。暗号化されたPDFはパスワードを入力して開きます。パスワードは保存しないため、後から元PDFを開き直す際には再入力が必要です。
2. **拡大率** で見やすい表示にし、**解像度** を72／144／216／288 dpiから選びます。表示倍率は範囲を選ぶための設定で、保存する画像の画素数は解像度で決まります。
3. ページ上をドラッグするか、左位置・上位置・幅・高さをパーセントで入力して範囲を指定します。軸・凡例・注記も含む範囲を確認し、必要なら **ページ全体に戻す** を使用します。
4. **出典を確認** で文献の題名・著者・年・URL、論文内ページ、図表番号を入力します。登録済み文献も選べます。PDFページ番号は選択したページから引き継ぎます。文献情報は手入力で確認し、ファイル名から入る題名も実資料に合わせて訂正してください。
5. **選択範囲を図として挿入** で確定します。元PDF全体と選択ページ全体のPNGを保持し、その上に切り抜き範囲を設定します。後で図を選び **元PDFから範囲を取り直す** を開くと、別ページ・解像度・範囲を選び直して **この図を更新** できます。

同じPDF・同じページの切り抜き変更では注釈を保持します。別ページまたは別のPDFへ取り込み直す場合は、旧ページの注釈を引き継ぎません。取り込み・更新は本文のUndo／Redoに対応します。画像の文字を読むOCRや、表を数値データへ変換する抽出機能はありません。

PDFは1ファイル20 MiB・5,000ページまで、ローカル素材の合計は50 MiBまでです。表示用PNGは800万画素・長辺4,096 pxを上限に描画し、大きいページは実際のdpiを下げます。画面に表示される画素数と実際のdpiを確認してください。

**HTML／ZIPには、選択したページのPNGに加えて元PDF全体が含まれます。** 使用していないページも含まれるため、共有前に原本全体が配布対象でよいことを確認してください。JSON／MarkdownはPDFへの参照とページ・切り抜き設定を保存し、原画像とPDF原本は別ファイルが必要です。

## 図・表・説明を領域へ割り当てる

スライドデザインの配置から **図・表・説明を領域に配置** を選びます。既存8配置に追加した9番目の配置です。

- 全幅上部、左側、右上、右下、全幅下部へブロックを割り当てます。
- 主領域の幅（20〜80%）、領域間の余白、左右入替、領域内の順序を指定します。
- 要素に名前を付けると、ナビゲーターからその名前で選択できます。
- キャプション・注釈・出典は図に付随して移動します。新しい未割当ブロックは全幅下部へ表示し、内容を消しません。
- 座標で手動配置した図は元の位置を保護します。領域へ入れる場合は **本文の流れに戻す** を選びます。
- 変更前後のプレビュー、現在／選択／全ページへの適用、個別設定の保護、専用の変更取消を使用できます。

表はテーマと合わせて交互行、ヘッダー背景、セル余白を設定できます。既存の役割別文字サイズ・本文密度・列幅・罫線と組み合わせます。内容量が多いときは検査結果を確認し、列幅を変えるかページを分けてください。

## 複数系列グラフ

グラフのPropertiesで **系列を追加** を選び、最大8系列、各200点まで編集できます。各系列に名前、色、線種、マーカーを設定できます。折れ線・散布図・棒、横棒の並列比較、値ラベル、軸範囲、軸名と単位に対応します。

データは `label,x,y` の3列です。CSVファイルの読み込みとテキスト貼り付け、表計算からコピーしたタブ区切りデータに対応します。系列ごとに入力し、**グラフを適用** で表示へ反映します。空欄や数値でない値は適用しません。出典とデータ種別（実測／解析／模式／混在）も保存します。数値軸は線形／対数（log10）を選べます。対数軸では値と誤差範囲を正にしてください。誤差棒は点ごとにX・Yの上下幅を指定でき、非対称な誤差にも対応します。CSVの追加列名は入力欄の例を参照してください。棒グラフの分類軸は対数化せず、誤差棒は値の方向だけに表示します。

## HTMLを読む・図を拡大する

Propertiesの **読者向けの補足** に、ページごとの詳しい説明と文献・PDFへのURLを入力します。出力したReport／Slide HTMLでは **詳しい説明** から開けます。図・グラフはクリック、または拡大ボタンで拡大できます。閉じるかEscで元のページ・操作位置へ戻ります。スライドのページ送りは補足・拡大画面を閉じてから操作します。

読者向け補足と発表者ノートは別々に保存します。ただし編集用HTMLには両方の編集情報を含みます。発表者ノートは秘密情報を隠す仕組みではありません。

先頭の見出しを削除しても、残った本文の識別情報から補足の所属を保ちます。ページ本文をすべて削除した場合や所属を確定できない場合は **未割当の補足** に原文を保持し、移動先ページを選んで **Nページへ補足を戻す** から復帰できます。

章別Report／Slideでは文献を全章で共有し、各章の補足を結合後のページへ引き継ぎます。別の章を取り込んだ際に同じ文献IDが異なる資料を指す場合は、IDを分けて両方を保持します。改ページせずに章を結合した場合も、それぞれの補足を表示します。

## 保存形式と検査

ヘッダーの **保存形式の違い** で、現在の文書にある図表を含めた対応範囲を確認できます。

| 形式           | 保持するもの・制限                                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HTML           | 編集データ、原画像、PDF原本全体とページ設定、構造化図解の部品・接続、SVGソース、切り抜き、注釈、文献、配置、グラフ元データ、補足。外部URL画像は通信が必要 |
| ZIP            | 文書と原画像・PDF原本全体を保存し、部品・ページ・切り抜きを再編集可能。章別Report／Slideの構成にはプロジェクトZIP                                         |
| JSON／Markdown | 編集データは保持。参照するローカル画像・PDF原本は別ファイルも必要。図解・PDF設定は属性、グラフはKUMIブロック、文献・配置・補足はメタデータへ保持          |
| Word／PPTX     | 図解・SVG・PDFページ・切り抜き・注釈の見た目を画像として保持、図の出典は文章化。PDF原本・部品の再編集情報は保持しない。領域配置はOffice独自の組版         |
| Wordのグラフ   | 全系列、単位、グラフの自由記入出典を編集可能なデータ表として保存                                                                                          |
| PPTXのグラフ   | 表示は先頭系列と既存スタイル。全系列のデータ・グラフの自由記入出典を発表者ノートへ保存。比較図の見た目にはHTML／PDFを使用                                 |
| PDFボタン      | 完成ページを画像化。文字検索・選択は不可。本文の検索・コピーには「出力比較・印刷」から印刷／PDF保存を使用                                                 |

表・グラフから共有文献の要点・PDFへ移動する機能はHTMLで利用できます。Word／PPTXには共有文献詳細を含めません。

既存Document JSON v1／v2、文書ZIP、編集情報付きHTMLを継続して読み込めます。新しい属性は任意項目なので、従来文書は変更せず開けます。未知の版や不正な構造は現在の文書へ適用しません。v1／v2の未知のブロック・文字装飾は、そのブロック全体のJSON原文と対象を保持します。外部HTMLも変換前の原文を保持します。Propertiesの **保持した取込原データ** を必要なときだけ開き、対象への移動・原文確認・保存ができます。原文は実行せず、HTML原文の保存拡張子は `.html.txt` です。外部リンク先のファイルや動作は保存しません。原文は合計5 MiB・1,000件までです。

**全ページをチェック** の結果から対象を選び、全幅配置・表分割などの修正へ進めます。表ツールバーの **表を次のページへ分割** では、縦結合を横切らない行境界を選び、見出し行を繰り返せます。内容・結合・列幅を保持し、Undoで戻せます。後半の表と後続本文が次のページへ移るため、後半は番号なしの続きとして表示し、新ページのデザインは既定設定を使います。両ページを確認してください。画像の元画素数と表示寸法の比も確認します。これは画像内文字のOCRや内容の正しさの判定ではありません。意図した重なりの除外は現在の文書版に対してだけ有効です。

## ブロックのまとまり・部品再利用

Propertiesの **ブロックのまとまり・再利用** で、同じページの図・表・説明を選びます。名前、グループ、配置ロック、順序、役割を設定し、領域への移動や配置を保持した複製ができます。ロックは配置とグループ操作を保護し、本文そのものの編集を禁止する設定ではありません。配置済みの複数図や図解内の図形は、辺・中央の整列、水平・垂直の均等間隔にも対応します。

名前を付けて **選択したまとまりを部品登録** すると、配置・共有文献・画像・PDF原本を保持したまま登録できます。登録部品を現在のページへ再挿入でき、元ブロックを削除しても部品の素材を保持します。部品はこの文書のHTML／ZIP／JSON／Markdownに保存します。JSON／Markdownでは素材ファイルも別途必要です。

本文と配置を同時に変える操作は **まとまり・配置の変更を取り消す** で直前の状態へ戻します。その後の別編集を上書きしないため、内容が変わった場合はこの取消を無効にします。

## 書式・文献・章管理

スライドデザインで、タイトル・見出し・本文・表・補足に加えて、リード文・図ラベル・出典の文字サイズ、色、行間、余白を指定できます。配色とページ余白を調整し、名前付きプリセットとして保存できます。ページ別設定を保護し、適用前に変更を比較します。画像に焼き込まれた文字と任意の外部SVG内部の文字は一括書式の対象外です。表ではセルの背景色を指定できます。

図・表・グラフの共有文献には、題名等に加えて **要点** と **PDF URL** を登録できます。出力HTMLの文献詳細から要点を読み、PDFを開いて元のページへ戻れます。PDF URLは外部リンクであり、PDF取り込みで保持する原本とは別です。

**章別プロジェクト** はSlideにも対応します。デッキを章として追加し、章順序・出力対象・全体目次・共通テーマ・章別テーマを指定します。ページの複製、前後移動、別章への移動も可能です。出力範囲の **この章／含める章すべて** はHTML・Office・PDF・出力比較に共通です。章構成と除外章も残す原本はプロジェクトZIPへ保存します。詳細は [章別プロジェクトガイド](./report-projects.ja.md) を参照してください。

## 出力比較と検索できるPDF

ヘッダーの **出力比較・印刷** を開くと、HTML表示と印刷用紙を切り替えて比較できます。**印刷／PDF保存** でブラウザーの印刷画面を開き、PDFを保存先に選びます。本文・表・数式は文字、グラフ・SVG図はベクターのまま印刷へ渡します。写真・PDFページ画像等は画像として残り、画像内の文字は検索できません。画像として印刷する要素は画面の一覧で確認できます。

検索できるPDFの印刷文書には日本語フォントも埋め込み、端末のフォントによる文字の置換を抑えます。印刷用の書体による折返しの違いは、この画面で確認できます。

印刷設定はヘッダー・フッターをオフ、背景のグラフィックをオンにし、ブラウザーの最終プレビューで改ページを確認してください。長いReportの自動分割はブラウザーに依存します。Slideのはみ出しは警告を確認して修正します。従来の **PDF** ボタンは画像化PDFを直接ダウンロードする経路です。どちらもKUMIの編集用原本にはならないため、HTML／ZIPも保存してください。

## 調査した実装・仕様

- [Tiptap insertContentAt](https://tiptap.dev/docs/editor/api/commands/content/insert-content-at)：位置を明示したブロック挿入に使用。
- [DOMPurify](https://github.com/cure53/DOMPurify)：SVGを表示するコピーの安全化に使用。原本は実行しない文字列として保持。
- [W3C CSS Gridの読み順](https://www.w3.org/TR/css-grid-2/#order-accessibility)：領域の左右を入れ替えた際の表示と読み順を確認。
- [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180.html)：引用符を含むCSV入力の解析に参照。
- [W3C dialog](https://www.w3.org/WAI/WCAG22/Techniques/html/H102)：図拡大・補足でフォーカスを戻す動作に参照。
- [MDN window.print](https://developer.mozilla.org/en-US/docs/Web/API/Window/print)：ブラウザー印刷画面を開く経路。
- [Google FontsのNoto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp)・[Noto Serif JP](https://github.com/google/fonts/tree/main/ofl/notoserifjp)：SIL OFLの日本語フォントを印刷用に同梱。改変と再生成手順は `src/export/fonts` に記録。
- [MDN Document.fonts](https://developer.mozilla.org/en-US/docs/Web/API/Document/fonts)：印刷前にフォントの読込完了を確認。
- [MDN 印刷用CSS](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Printing)：既存HTML印刷経路と、直接画像PDFとの違いを確認。
- [Mozilla PDF.jsの例](https://mozilla.github.io/pdf.js/examples/)：ローカルPDFのページ描画と倍率指定に使用。元PDF、選択ページのPNG、切り抜き座標、出典は文書と関連付けて保持し、保存後の再選択・再切り抜きへつなぎます。

要望書のSSI実資料・操作画像は同じ添付として参照できなかったため、実装確認には架空の小作例を使用しました。65枚の同一再現や原資料の内容検証を行ったものではありません。
