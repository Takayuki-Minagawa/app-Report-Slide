# 図表を作り、保存後も編集する

## 最初に試す

左の **サンプルを開く → 図表サンプル（5ページ）** で、模式図、原図＋比較表＋条件、全幅表、2系列グラフ、読者向け補足を試せます。数値と原資料は機能説明用の架空データです。起動時には自動で開きません。

1. ページ番号・タイトルで対象を検索し、**編集対象一覧** から図や表を選びます。
2. 図表の挿入先を **選択ブロックの後／現在のページ末尾／カーソル位置** から選びます。標準では選択した表の外へ挿入されます。挿入結果にはページ番号を表示します。
3. 右側の設定を変更して適用します。本文の移動・複製、図・表・グラフの変更はUndoで戻せます。スライドデザインには専用の直前変更取消があります。文献・補足などの文書設定は本文のUndoとは別です。
4. **HTML** または **ZIP** を保存します。別のブラウザー状態で開き、図のラベル・表の値・切り抜き・出典を再編集できます。

## SVG図解と原図

**SVG図解を挿入** は3状態の模式図を追加します。図を選択し、**SVGソース・ラベルを編集** を開くと、ラベルの文字と矢印の向きを変更できます。任意のSVGファイルを読み込み、ソースを修正することもできます。

通常の画像は画像としての配置、SVG原本を指定した図はソース編集が可能、と画面に表示します。SVG原本は文字列として保持し、表示用には実行要素・外部参照・埋込画像・styleを除去したコピーを使います。SVGソースは1 MBまでです。外部HTMLから変換したSVG画像の内部編集には、必要に応じてSVG原本を指定してください。

**原画像の切り抜き・注釈** は元画像に対する割合で範囲を指定します。切り抜きを解除すれば原画像全体へ戻せます。矢印・囲み・番号・説明を別レイヤーとして追加でき、位置・色・文字サイズを数値で変更できます。注釈の座標は元画像に固定されるため、切り抜き範囲を変えても同じ箇所を指します。原画像の縦横比は保持します。

**図の由来・共有文献** には文献ID、題名、著者・年、URLを登録します。同じ文献IDを使う図は、文献の訂正を共有します。PDFページ、論文内ページ、図表番号、由来（原図／一部切り抜き／再作図／概念図）、注記は図ごとに指定します。共有文献を保存したあと **図の編集を適用** で図との関連を確定します。由来と文献情報はキャプションに続けて表示します。

今回のSVG内部編集はソース・ラベル・矢印の操作です。任意の図形をドラッグして接続線が追従する図形エディターや、一般的なグループ化は含みません。

## 図・表・説明を領域へ割り当てる

スライドデザインの配置から **図・表・説明を領域に配置** を選びます。既存8配置に追加した9番目の配置です。

- 全幅上部、左側、右上、右下、全幅下部へブロックを割り当てます。
- 主領域の幅（20〜80%）、領域間の余白、左右入替、領域内の順序を指定します。
- 要素に名前を付けると、ナビゲーターからその名前で選択できます。
- キャプション・注釈・出典は図に付随して移動します。新しい未割当ブロックは全幅下部へ表示し、内容を消しません。
- 座標で手動配置した図は元の位置を保護します。領域へ入れる場合は **本文の流れに戻す** を選びます。
- 変更前後のプレビュー、現在／選択／全ページへの適用、個別設定の保護、専用の変更取消を使用できます。

表はテーマと合わせて交互行、ヘッダー背景、セル余白を設定できます。既存の役割別文字サイズ・本文密度・列幅・罫線と組み合わせます。内容量が多いときは検査結果を確認し、列幅を変えるかページを分けてください。

## 複数系列グラフ

グラフのPropertiesで **系列を追加** を選び、最大8系列、各200点まで編集できます。各系列に名前、色、線種、マーカーを設定できます。折れ線・散布図・棒、横棒の並列比較、値ラベル、軸範囲、軸名と単位に対応します。

データは `label,x,y` の3列です。CSVファイルの読み込みとテキスト貼り付け、表計算からコピーしたタブ区切りデータに対応します。系列ごとに入力し、**グラフを適用** で表示へ反映します。空欄や数値でない値は適用しません。出典とデータ種別（実測／解析／模式／混在）も保存します。対数軸と誤差棒は後続項目です。

## HTMLを読む・図を拡大する

Propertiesの **読者向けの補足** に、ページごとの詳しい説明と文献・PDFへのURLを入力します。出力したReport／Slide HTMLでは **詳しい説明** から開けます。図・グラフはクリック、または拡大ボタンで拡大できます。閉じるかEscで元のページ・操作位置へ戻ります。スライドのページ送りは補足・拡大画面を閉じてから操作します。

読者向け補足と発表者ノートは別々に保存します。ただし編集用HTMLには両方の編集情報を含みます。発表者ノートは秘密情報を隠す仕組みではありません。

先頭の見出しを削除しても、残った本文の識別情報から補足の所属を保ちます。ページ本文をすべて削除した場合や所属を確定できない場合は **未割当の補足** に原文を保持し、移動先ページを選んで **Nページへ補足を戻す** から復帰できます。

章別Reportでは文献を全章で共有し、各章の補足を結合後のページへ引き継ぎます。別の章を取り込んだ際に同じ文献IDが異なる資料を指す場合は、IDを分けて両方を保持します。改ページせずに章を結合した場合も、それぞれの補足を表示します。

## 保存形式と検査

ヘッダーの **保存形式の違い** で、現在の文書にある図表を含めた対応範囲を確認できます。

| 形式           | 保持するもの・制限                                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| HTML           | 編集データ、取り込んだ原画像、SVGソース、切り抜き、注釈、共有文献、複合配置、グラフ元データ、補足。外部URL画像は通信が必要          |
| ZIP            | 文書と取り込んだ素材。章別Reportの構成にはプロジェクトZIP                                                                           |
| JSON／Markdown | 編集データ。ローカル画像は別ファイルも必要。SVGソースなどの拡張情報は属性、グラフはKUMIブロック、文献・配置・補足はメタデータへ保持 |
| Word／PPTX     | SVG・切り抜き・注釈の見た目は1枚の画像に統合、出典は文章化。内部編集情報は再編集できない。領域配置はOffice独自の組版                |
| Wordのグラフ   | 全系列、単位、出典を編集可能なデータ表として保存                                                                                    |
| PPTXのグラフ   | 表示は先頭系列と既存スタイル。全系列のデータ・出典を発表者ノートへ保存。比較図の見た目にはHTML／PDFを使用                           |
| PDFボタン      | 完成ページを画像化。文字検索・選択は不可。本文の検索・コピーにはHTMLからブラウザーの印刷／PDF保存を使用                             |

既存Document JSON v1／v2、文書ZIP、編集情報付きHTMLを継続して読み込めます。新しい属性は任意項目なので、従来文書は変更せず開けます。未知の版や不正な構造は現在の文書へ適用しません。対応していない構造を汎用ブロックとして内部編集する機能は未実装で、元ファイルを保存しておく必要があります。

**全ページをチェック** の結果から対象を選び、列幅・全幅配置・表の分割などの修正候補を確認できます。画像の元画素数と表示寸法の比も確認します。これは画像内文字のOCRや内容の正しさの判定ではありません。意図した重なりの除外は現在の文書版に対してだけ有効です。

## 調査した実装・仕様

- [Tiptap insertContentAt](https://tiptap.dev/docs/editor/api/commands/content/insert-content-at)：位置を明示したブロック挿入に使用。
- [DOMPurify](https://github.com/cure53/DOMPurify)：SVGを表示するコピーの安全化に使用。原本は実行しない文字列として保持。
- [W3C CSS Gridの読み順](https://www.w3.org/TR/css-grid-2/#order-accessibility)：領域の左右を入れ替えた際の表示と読み順を確認。
- [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180.html)：引用符を含むCSV入力の解析に参照。
- [W3C dialog](https://www.w3.org/WAI/WCAG22/Techniques/html/H102)：図拡大・補足でフォーカスを戻す動作に参照。
- [MDN 印刷用CSS](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Printing)：既存HTML印刷経路と、直接画像PDFとの違いを確認。
- [Mozilla PDF.jsの例](https://mozilla.github.io/pdf.js/examples/)：R12の候補。ページ描画・倍率・キャンバスの順次処理を利用できる一方、元PDFの保存、座標、出典、再切り抜きの管理も必要なため、独立した後続機能として扱います。

要望書のSSI実資料・操作画像は同じ添付として参照できなかったため、実装確認には架空の小作例を使用しました。65枚の同一再現や原資料の内容検証を行ったものではありません。
